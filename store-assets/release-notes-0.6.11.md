# 飞书 To Markdown 0.6.11

发布日期：2026-11-11

## 更新内容

- 移除直接全文导出 Markdown 功能，删除对应入口、页面、Worker、文档接口请求代码及打包配置。
- 扩展仅处理用户本次复制、粘贴或点击“转换剪贴板”提供的内容，结果写回剪贴板或编辑器。
- 保留代码块正文、缩进、空行、语言标记及嵌套围栏的转换修复。
- 保留 VS Code 等编辑器语法着色 HTML 中的 Markdown 源码识别。
- Markdown 表格继续默认使用飞书文档表格，保留嵌套列表中的正文、代码、表格和图片。
- 隐私政策、权限用途说明、商店描述和审核测试步骤已同步更新。权限清单未新增；scripting 仅用于为授权的企业域名注册内置脚本，activeTab 用于显示域名生效状态。

## 发布包

请上传 `feishu-to-markdown-edge-0.6.11.zip` 至已有 Edge 商店条目。`SHA256SUMS` 提供校验值。

0.6.10 包含已经移除的全文导出功能，请使用本版本替代。操作步骤和审核文案见 [Edge 商店更新指南](https://github.com/wudi-7mi/feishu-to-markdown/blob/v0.6.11/store-assets/edge-update-guide.md)。

本地开发版更新后，请重新加载扩展并刷新已经打开的飞书页面。

## 验证

- 扩展脚本、Manifest、资源和 Markdown 转换校验通过。
- Microsoft Edge 浏览器集成测试覆盖代码块、文档表格、语法着色 Markdown 源码、弹窗剪贴板转换及开关持久化，并确认全文导出入口已移除。
- 发布 ZIP 和本地运行目录均不包含已移除的导出文件。

本项目为独立开发的第三方工具，非飞书或 Lark 官方产品。
