# 飞书 To Markdown 0.6.10

此历史版本包含已移除的全文导出功能，已由 [0.6.11](https://github.com/wudi-7mi/feishu-to-markdown/releases/tag/v0.6.11) 替代。请使用 0.6.11 的发布包提交 Edge 商店。

发布日期：2026-11-11

## 更新内容

- 支持飞书文档与 Markdown 双向转换，复制时同时保留原始飞书富文本。
- 修正代码块粘贴格式，使用飞书原生正文结构和语言标记，保留缩进、空行及特殊字符。
- 支持 VS Code 等编辑器附带语法着色 HTML 的 Markdown 源码，正确处理四反引号 Markdown 围栏中嵌套的 JSON 代码块。
- Markdown 表格默认生成飞书文档表格，直接粘贴和“转换剪贴板”使用相同格式。
- 改进飞书嵌套列表的复制转换，保留列表中的正文、代码块、表格和图片。
- 新增“导出当前文档”实验功能，支持新版文档与知识库文档的分页读取、内容补全、取消、重试和本地 Markdown 文件导出。
- 更新隐私说明与商店审核材料，说明全文导出的同源读取和本地文件保存行为。权限清单未新增。

## 下载与更新

- Edge 商店上传包：`feishu-to-markdown-edge-0.6.10.zip`。
- `SHA256SUMS` 提供发布包的 SHA-256 校验值。
- 已从 Edge 商店安装的用户，在商店更新通过审核后可获取新版本；本地开发版需要重新加载扩展并刷新已打开的飞书页面。
- Edge 商店更新操作见 [更新指南](https://github.com/wudi-7mi/feishu-to-markdown/blob/v0.6.10/store-assets/edge-update-guide.md)。

## 已知限制

- 全文导出为实验功能，需要当前账号有权访问源文档，源文档所在域名已配置并授权。
- 图片保留在线引用，复杂组件可能以占位提示表示；请核对导出任务页给出的提示。
- 自动化测试使用本机浏览器和模拟编辑器，不代表所有飞书服务版本均已验证。

## 验证

- 扩展校验、Markdown 转换测试和 21 项全文导出测试通过。
- Microsoft Edge 浏览器集成测试通过，覆盖粘贴格式、弹窗剪贴板转换、真实 MV3 扩展加载、Worker、取消、流式输出和文件下载。
- 使用原生表格样本核对转换结果，4 行、12 个单元格文字保留完整。

本项目为独立开发的第三方工具，非飞书或 Lark 官方产品。
