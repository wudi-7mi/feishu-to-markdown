# 飞书 To Markdown 0.6.14

- 为“暂时无法在飞书文档外展示此内容”等提示增加具体类型标注，兼容企业文档名称。
- 根据复制内容已有的明确类型线索，标注画板、思维导图、流程图/图表、电子表格、多维表格、音视频、小组件等；缺少线索时标为未识别，不猜测。
- 已核对原生画板样本的 `whiteboard` 类型。其他规则使用兼容性样本验证，仍需要更多原生组件样本；画板内部的思维导图在没有独立类型标记时仍归类为画板。
- 保留已有预览图、链接及周围文字，不改写代码里的示例提示；多次复制占位文字不会重复标注。
- README 增加按 31 组常见格式整理的支持与缺口清单。文字背景色、下划线、数学公式等尚无完整转换，清单未将其列为已支持。
- 修正本地剪贴板诊断工具的中文 UTF-8 解码，避免读取原生 HTML 时产生乱码；诊断内容不写入文件。

验证：转换器、后台与 Edge 浏览器回归通过，覆盖原生画板样本的脱敏结构、企业提示、类型兜底、预览和链接保留，以及已有的表格、代码块和开关流程。

Edge 包：`dist/feishu-to-markdown-edge-0.6.14.zip`。本地开发版更新后，在 `edge://extensions/` 重新加载扩展。

权限和数据处理范围没有新增，仅处理用户这次复制或粘贴提供的内容，不请求文档或组件正文接口。
