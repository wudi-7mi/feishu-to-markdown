# 飞书 To Markdown 0.6.12

- 修复功能关闭时打开页面，之后开启仍需刷新才能使用的问题。
- 开关实时更新已经打开的页面；开启功能或授权域名后，为已配置且已授权的页面补充加载内置转换脚本。
- 修复重复加载脚本造成重复监听、较早的设置读取覆盖最新开关状态的问题。关闭复制转换时停止尚未开始的剪贴板重试和写回。
- 权限清单未新增。`scripting` 的用途说明已同步更新；仍仅处理用户主动复制、粘贴或显式转换剪贴板提供的内容，全文导出功能保持移除。

验证通过：转换器测试、后台域名和授权范围测试，以及真实 Edge MV3 弹窗中开启、关闭、重新开启的无刷新测试。

Edge 包：`dist/feishu-to-markdown-edge-0.6.12.zip`。开发版更新后需要在 `edge://extensions/` 重新加载扩展一次，以载入修复；旧页面若仍运行旧脚本，可刷新一次。之后日常切换功能无需刷新页面。
