# 飞书 To Markdown 0.6.15

- 补充 Markdown 内嵌 HTML：保留剪贴板已有的文字颜色、背景色、下划线、上下标、段落对齐与缩进、七至九级标题语义、提示块、分栏、折叠及合并/带样式表格。
- 提取代码块语言、公式 LaTeX 或 MathML，以及已有的提及、卡片、附件名称和静态链接。只处理复制内容，不获取组件或附件正文。
- 内嵌 HTML 使用标签、CSS 和 URL 允许列表，过滤脚本、事件属性及活动嵌入。随包提供 MIT 许可的 KaTeX，仅用于本地 MathML 输出，无 CDN 或运行时网络依赖。
- 修复表格内代码和 LaTeX 中管道符的往返转义，保留代码中的字面量 HTML 与美元符号，避免普通价格被误作公式。
- 包含此前的即时开关、表格单元格列表导出和特殊组件类型提示；权限和数据范围没有新增，不提供全文导出。

实际企业文档测试页确认颜色、背景、下划线、居中、合并单元格、列宽和带语言的代码块可导入。其导入器仍将分栏、折叠、高级标题和表格内 HTML 列表降级，单元格外观也可能丢失。即使使用该站点自身复制的表格 HTML，列表编号也未恢复。公式粘贴明确保留源码及前后正文，不宣称恢复原生公式。外部 Markdown 渲染器也可能过滤 HTML 样式，完整条件见 [README 格式清单](../README.md#格式支持盘点)。

验证：转换与后台单元测试、Edge 浏览器中的富文本往返、HTML 过滤、代码/表格粘贴、真实 MV3 扩展开关及弹窗测试；另在提供的企业文档测试页通过原生粘贴核对上述结果。页面内仅保留合成测试内容。

Edge 包：`dist/feishu-to-markdown-edge-0.6.15.zip`。本地开发版更新后，在 `edge://extensions/` 重新加载扩展，再刷新原有文档页一次以载入新代码。此次为本地构建，商店与 GitHub 发布需另行操作。
