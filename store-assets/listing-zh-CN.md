# 飞书 To Markdown

飞书 To Markdown 是一款支持双向文档转换的 Edge 扩展。在飞书文档中按下 Ctrl+C，可将标题、粗体、链接、图片、列表、任务项、引用、代码块和表格等结构转换为 Markdown。把 Markdown 粘贴到飞书编辑区时，扩展也能将其转换为飞书可编辑的富文本。所有转换均在浏览器本地完成，无需打开中间转换页面。

除了飞书和 Lark 官方域名，扩展还支持购买飞书服务并使用企业专属域名的文档系统。这类企业可以在设置页添加自己的访问域名，并通过 Edge 的按需授权机制单独授权，无需为插件开放所有网站的访问权限。这是飞书 To Markdown 区别于只适配公共飞书域名的转换工具的重要特点。

扩展提供复制开关、Markdown 粘贴转换开关和生效域名设置。默认支持飞书与 Lark 官方域名；企业自定义域名仅在用户主动授权后启用。支持从 VS Code 等编辑器复制的 Markdown 源码，保留代码块的缩进、空行和语言信息，Markdown 表格默认粘贴为飞书文档表格。

设置页还提供“导出当前文档”实验功能，可将新版文档或知识库文档全文导出为本地 Markdown 文件，无需全选或复制。支持分页读取、缺失内容补全、取消和失败重试。图片保留在线引用；复杂组件会给出提示，需要结合原文核对。

扩展只响应用户主动发起的复制、粘贴、转换剪贴板或全文导出操作。文档内容在本地处理；除按用户要求保存的导出文件外，不上传、出售或持久化保存文档内容，不包含广告、统计分析或远程代码。全文导出使用原文档网站已有的登录状态，只发起同源读取请求，不提取 Cookie 或令牌。

使用方法：安装扩展后刷新飞书文档。选中内容并按 Ctrl+C 可获得 Markdown；从其他应用复制 Markdown 后，在飞书编辑区按 Ctrl+V 可粘贴为富文本。工具栏弹窗还提供显式“转换剪贴板”操作。

飞书 To Markdown 是独立开发的第三方工具，并非飞书或 Lark 官方产品，也未获得其背书。
