# 飞书 To Markdown

飞书 To Markdown 是一款专注于文档复制场景的 Edge 扩展。在飞书文档中选中一个或多个内容块后，直接按下 Ctrl+C，扩展会等待飞书完成原生富文本复制，在浏览器本地将标题、粗体、斜体、删除线、链接、图片、列表、任务列表、引用、代码块和表格等常见结构转换为 Markdown，并将结果写回剪贴板。你可以随后直接粘贴到代码仓库、知识库、笔记工具或 AI 对话中，无需打开中间转换页面。

扩展提供总开关和生效域名设置。默认支持飞书与 Lark 官方域名；企业自定义域名仅在用户主动授权后启用。扩展只响应用户主动发起的 Ctrl+C 操作，所有转换均在当前浏览器本地完成，不会上传或保存文档内容，也不包含广告、统计分析或远程代码。

使用方法：安装扩展后刷新飞书文档，选中内容并按 Ctrl+C，即可获得 Markdown。点击工具栏图标可以开启或关闭功能、查看默认域名，或添加并授权企业自定义域名。

飞书 To Markdown 是独立开发的第三方工具，并非飞书或 Lark 官方产品，也未获得其背书。
