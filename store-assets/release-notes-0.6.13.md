# 飞书 To Markdown 0.6.13

- 修复表格单元格中的说明和列表项粘成一段、编号与换行丢失的问题。
- 保留有序列表、无序列表、嵌套层级、任务勾选和段落；将 Markdown 表格粘贴回飞书时重建单元格内列表。
- 正确区分单元格换行与代码、转义文本中的字面量 `<br>`。仅识别不带属性的换行标记，其他 HTML 继续作为文本处理。
- 修复多次转换后表头加粗格式累积，以及空列表项可能导致解析停滞的问题。
- 包含 0.6.12 的开关即时生效修复。权限和数据处理范围没有新增。

验证：转换器和后台测试通过；Edge 浏览器回归覆盖原复制样本的脱敏结构、四条编号列表、嵌套与任务项、多次往返，以及交给编辑器粘贴处理器的列表结构。自动化测试使用本机文档，不访问真实飞书账户。
